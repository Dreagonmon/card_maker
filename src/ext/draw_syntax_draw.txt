Canvas / OffscreenCanvas 矩形、图片与文本绘制指令文档
======================================================

说明
----
1. 本文档整理“矩形快捷绘制”、“图片绘制”与“区域文本绘制”指令。
2. 包含：fillrect、strokerect、clearrect、drawimage、filltext、stroketext。
3. 不包含：路径构建与路径绘制/裁剪、样式设置、坐标变换。
4. 这些指令作用于当前 2D 渲染上下文。
5. 参数只支持：数字字面量、字符串字面量、${var} 外部变量引用。
6. 矩形、图片、文本指令都不经过当前路径，与 beginpath / moveto 等路径指令互不影响。
7. 图片参数为字符串，对应内部资源中的一个文件名。
8. 文本绘制必须提供 bbox 区域；解析器负责文本测量、换行、对齐、行高计算，并将绘制裁剪到 bbox 内。
9. 不支持 | 转义；| 只作为参数分隔符。需要包含 | 的字符串只能通过 ${var} 传入，但变量值中的 | 不会重新分割参数。


一、总语法
----------
<func>:<param1>|<param2>|...|<paramn>

说明：
- 每次调用 setString("@draw", "<func>:...") 执行一条指令。
- func 统一小写。
- 多参数指令使用 | 分隔参数。
- 本文档所有指令都带参数，冒号不可省略（零参数指令省略冒号的规则只适用于路径/样式文档中的无参数指令）。
- 不支持 | 转义；需要包含 | 的字符串只能通过 ${var} 传入，且不会重新分割参数。


二、通用约定
------------
1. 参数取 : 后到行尾，去掉首尾空白。
2. 解析顺序：
   a. 先按指令规则用 | 分割参数。
   b. 再对每个参数执行 ${var} 字符串替换。
   c. 最后把替换后的整个参数字符串解析为目标类型（数字、字符串或资源名）。
3. ${var} 一律按字符串替换处理，不保留变量原始类型。
4. 变量替换后不再重新按 | 分割参数。
5. 变量名规则：[A-Za-z_][A-Za-z0-9_]*
6. 数字参数替换后必须能解析为数字。
7. 图片参数替换后必须为非空字符串，并能在内部资源中找到对应文件。
8. 文本参数允许为空字符串；为空时该指令不绘制任何内容，但仍会消耗样式状态。
9. 未知变量、非法参数、资源不存在应报错。


三、矩形绘制指令
----------------
指令：fillrect:<x>|<y>|<w>|<h>
参数：x, y, w, h
类型/约束：数字 / ${var}
作用：直接填充矩形，不经过当前路径
说明：
  - w、h 可为负数，Canvas 会按反向绘制。
  - 不影响当前路径状态。
示例：
  fillrect:10|10|200|100
  fillrect:${x}|${y}|${w}|${h}

指令：strokerect:<x>|<y>|<w>|<h>
参数：x, y, w, h
类型/约束：数字 / ${var}
作用：直接描边矩形，不经过当前路径
说明：
  - w、h 可为负数，Canvas 会按反向绘制。
  - 不影响当前路径状态。
示例：
  strokerect:20|20|180|80
  strokerect:${x}|${y}|${w}|${h}

指令：clearrect:<x>|<y>|<w>|<h>
参数：x, y, w, h
类型/约束：数字 / ${var}
作用：将矩形区域清除为透明黑
说明：
  - w、h 可为负数，Canvas 会按反向清除。
  - 不影响当前路径状态。
示例：
  clearrect:0|0|600|600
  clearrect:${x}|${y}|${w}|${h}


四、图片绘制指令
----------------
指令：drawimage:<image>|<dx>|<dy>
参数：image, dx, dy
类型/约束：image 为字符串 / ${var}；dx、dy 为数字 / ${var}
作用：按图片原尺寸绘制到目标坐标
示例：
  drawimage:logo.png|10|10
  drawimage:${img}|10|10

指令：drawimage:<image>|<dx>|<dy>|<dw>|<dh>
参数：image, dx, dy, dw, dh
类型/约束：image 为字符串 / ${var}；dx、dy、dw、dh 为数字 / ${var}
作用：将图片缩放到目标矩形绘制
说明：
  - dw、dh 可为负数，Canvas 会按翻转方式绘制。
示例：
  drawimage:logo.png|10|10|200|100
  drawimage:${img}|10|10|${w}|${h}

指令：drawimage:<image>|<sx>|<sy>|<sw>|<sh>|<dx>|<dy>|<dw>|<dh>
参数：image, sx, sy, sw, sh, dx, dy, dw, dh
类型/约束：image 为字符串 / ${var}；其余为数字 / ${var}
作用：裁剪图片源矩形并缩放到目标矩形绘制
说明：
  - sx、sy、sw、sh 为源矩形，sw、sh 必须非负。
  - dx、dy、dw、dh 为目标矩形，dw、dh 可为负数。
示例：
  drawimage:logo.png|0|0|100|100|10|10|200|200
  drawimage:${img}|${sx}|${sy}|${sw}|${sh}|${dx}|${dy}|${dw}|${dh}

图片参数说明：
  - image 为内部资源中的一个文件名，如 logo.png、icons/star.svg。
  - 无协议符号，不支持 URL 等外部路径。
  - 运行时由资源系统解析为 CanvasImageSource（如 ImageBitmap、HTMLImageElement、OffscreenCanvas 等）。
  - 执行 drawimage 前，资源系统应确保图片已加载；若未加载或加载失败，应报错并中止当前批次。
  - image 不能为空字符串。


五、文本绘制指令
----------------
说明：
  - 文本绘制必须提供 bbox 区域。
  - 解析器负责：文本测量、自动换行、水平对齐、垂直对齐、行高计算、裁剪到 bbox。
  - 文本绘制不经过当前路径，也不影响当前路径。
  - 文本样式由样式指令提供：font、textalign、textbaseline、direction、letterSpacing、wordSpacing、lineheight。
  - 填充文本使用当前 fillStyle；描边文本使用当前 strokeStyle、lineWidth、lineJoin、lineCap。
  - text 参数固定位于参数串最后；第 4 个 | 之后的全部内容整体作为 text，因此 text 内部可以包含 |。

指令：filltext:<x>|<y>|<w>|<h>|<text>
参数：x, y, w, h, text
类型/约束：
  - x、y、w、h 为数字 / ${var}，w、h 必须为正数。
  - text 为字符串 / ${var}，可包含 | 与未经转义的换行符，可为空。
作用：在 bbox 区域内填充绘制文本
说明：
  - 文本在 bbox 内自动换行。
  - 超出 bbox 的内容会被裁剪，不绘制到区域外。
  - 行高由样式指令 lineheight 控制。
示例：
  filltext:10|10|200|100|Hello World
  filltext:10|10|200|100|第一行\n第二行
  filltext:10|10|200|100|A|B
  filltext:${x}|${y}|${w}|${h}|${text}

指令：stroketext:<x>|<y>|<w>|<h>|<text>
参数：x, y, w, h, text
类型/约束：与 filltext 相同
作用：在 bbox 区域内描边绘制文本
说明：
  - 布局、换行、对齐、行高、裁剪规则与 filltext 完全一致。
  - 使用当前 strokeStyle、lineWidth、lineJoin、lineCap 等描边样式。
示例：
  stroketext:10|10|200|100|Hello World
  stroketext:${x}|${y}|${w}|${h}|${text}

文本布局规则：
  1. 水平对齐：
     - textalign 为 start / left：文本在 bbox 内朝开始方向对齐。
     - textalign 为 center：文本在 bbox 内水平居中。
     - textalign 为 end / right：文本在 bbox 内朝结束方向对齐。
     - 其他值按 left 处理。
  2. 垂直对齐：
     - textbaseline 为 top / hanging：文本从 bbox 顶部开始排列。
     - textbaseline 为 middle：文本整体在 bbox 内垂直居中。
     - textbaseline 为 bottom / alphabetic / ideographic：文本在 bbox 底部结束。
     - 其他值按 top 处理。
  3. 自动换行：
     - 按 bbox 宽度与当前 font 进行测量。
     - 优先在空格处断行；单词超过 bbox 宽度时按字符拆分。
     - 未转义字面的换行符 强制换行。
  4. 行高：
     - 行高由样式指令 lineheight 提供，默认为 1.2。
     - 实际行高 = 当前 font 字号 × lineheight。
     - Canvas 原生不支持行高属性；解析器需自行记录 lineheight，并在绘制多行文本时计算行间距。
     - lineheight 只影响多行布局，不影响单行文本。
  5. 裁剪：
     - 解析器应在绘制前将绘制区域裁剪到 bbox。
     - 推荐实现：save → beginPath → rect(x, y, w, h) → clip → 绘制文本 → restore。
     - 不允许文本绘制溢出 bbox。
  6. 空文本：
     - text 为空字符串时，不绘制任何内容，但指令仍视为成功执行。
  7. 无效 bbox：
     - w <= 0 或 h <= 0 时报错。


六、参数分割规则
----------------
1. fillrect、strokerect、clearrect：
   按 | 分割为恰好 4 个参数：x、y、w、h。
   每个参数先做 ${var} 字符串替换，再解析为数字。
   参数个数不为 4 时报错。

2. drawimage：
   按 | 分割全部参数。
   第一个参数为 image 字符串，整体保留，不再按 | 分割。
   剩余参数为数字，按个数区分重载：
     - 参数总数 3：image, dx, dy
     - 参数总数 5：image, dx, dy, dw, dh
     - 参数总数 9：image, sx, sy, sw, sh, dx, dy, dw, dh
   参数总数不为 3、5 或 9 时报错。
   变量替换后不会重新分割参数。
   若 image 变量值包含 |，会作为 image 字符串的一部分，不会新增参数。

3. filltext、stroketext：
   参数串按“前 4 个 |”分割：
     - 前 4 段依次为 x、y、w、h。
     - 第 4 个 | 之后的全部内容（包括其中的 |）整体作为 text。
   参数串必须至少包含 4 个 |；否则报错。
   分割完成后再对每个参数执行 ${var} 替换。
   text 替换后即使包含 |，也不会重新分割参数。
   示例：
     filltext:0|0|100|100|Hello
       → x=0, y=0, w=100, h=100, text="Hello"
     filltext:0|0|100|100|A|B
       → x=0, y=0, w=100, h=100, text="A|B"
     filltext:0|0|100|100|
       → text=""

4. 所有矩形、图片、文本指令：
   每个参数先做 ${var} 字符串替换，再按目标类型解析。
   数字参数替换后必须能解析为数字，否则报错。
   image 替换后必须为非空字符串，否则报错。
   text 替换后允许为空字符串。


七、变量引用规则
----------------
1. 整个参数为变量：
   fillrect:${x}|${y}|${w}|${h}
   drawimage:${img}|10|10
   filltext:${x}|${y}|${w}|${h}|${text}

2. 变量嵌入字符串：
   drawimage:icons/${name}.png|10|10
   filltext:10|10|200|100|Hello, ${name}!

3. 图片参数：
   drawimage:${img}|10|10
   先按 | 分割参数，再替换变量。
   变量值中的 | 不会重新分割参数，会作为 image 字符串的一部分。

4. 文本参数：
   filltext:${x}|${y}|${w}|${h}|${text}
   先按前 4 个 | 分割出 bbox，剩余部分整体为 text。
   再替换变量；text 变量值中的 | 不会重新分割参数。

5. 矩形参数：
   fillrect:${x}|${y}|${w}|${h}
   先按 | 分割为 4 个参数，再逐个替换变量并解析为数字。

6. 变量未定义时建议报错并中止当前批次。


八、完整示例
------------
# 矩形快捷绘制
fillstyle:#ff6600
fillrect:10|10|200|100

strokestyle:#333333
linewidth:4
strokerect:20|20|180|80

clearrect:0|0|600|600

# 图片绘制：原尺寸
drawimage:logo.png|10|10

# 图片绘制：缩放到目标矩形
drawimage:logo.png|10|10|200|100

# 图片绘制：裁剪源矩形并缩放
drawimage:logo.png|0|0|100|100|10|10|200|200

# 文本绘制：单行
font:16px sans-serif
fillstyle:#222222
textalign:left
textbaseline:top
lineheight:1.5
filltext:10|10|300|40|Hello World

# 文本绘制：自动换行 + 显式换行 + 行高
textalign:center
textbaseline:middle
lineheight:1.6
filltext:10|60|300|120|这是一段较长的文本，解析器会根据 bbox 宽度自动换行。\n这是第二段。

# 文本绘制：text 中包含 |
textalign:left
filltext:10|190|300|40|A|B|C

# 文本绘制：描边
strokestyle:#ff0000
linewidth:2
stroketext:10|240|300|80|描边文本示例

# 使用变量
filltext:${x}|${y}|${w}|${h}|${text}
drawimage:${img}|${dx}|${dy}|${dw}|${dh}


九、解析与校验建议
------------------
1. 按每条命令解析，先找第一个 : 分割 func 和参数串。
2. func 统一转小写后匹配指令。
3. fillrect、strokerect、clearrect 必须恰好 4 个参数；每个参数替换变量后必须能解析为数字。
4. drawimage 按 | 分割全部参数，参数总数必须为 3、5 或 9。
   第一个参数为 image 字符串，替换变量后必须为非空字符串。
   其余参数替换变量后必须能解析为数字。
5. drawimage 的源矩形 sw、sh 必须非负；dw、dh 可为负数。
6. filltext、stroketext 必须至少包含 4 个 |。
   前 4 段替换变量后必须能解析为数字，且 w、h 必须为正数。
   第 4 个 | 之后的全部内容整体作为 text，替换变量后允许为空。
7. 文本绘制时，解析器应：
   - 使用当前 font、textalign、textbaseline、direction、letterSpacing、wordSpacing 进行布局。
   - 读取当前 lineheight（默认 1.2），按“font 字号 × lineheight”计算实际行高。
   - 使用 measureText 测量文本宽度，按 bbox 宽度自动换行。
   - 将 未经转义的换行符 解释为强制换行。
   - 将绘制区域裁剪到 bbox。
   - 填充文本使用 fillStyle；描边文本使用 strokeStyle、lineWidth、lineJoin、lineCap。
   - 行高只影响多行布局，不影响单行文本。
8. 图片资源不存在或未加载时，报错并中止当前批次。
9. 不支持 | 转义；变量值中的 | 不会重新分割参数。
10. 矩形、图片、文本指令不改变当前路径状态；路径状态仍由路径指令负责。
11. 样式由 fillstyle、strokestyle、linewidth、font、textalign、textbaseline、lineheight 等样式指令负责，本文档指令只负责像素输出。
12. 文本绘制指令应在内部 save / restore，避免 clip 影响后续绘制。
